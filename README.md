## Features

- **Simple & Fast:** Paste any YouTube link to automatically preview video info and download.
- **Audio & Video Formats:**
  - **Audio Only (MP3):** Default high-quality 320 kbps conversion.
  - **Video (MP4):** Up to 4K / 8K resolution with crisp merged audio.
  - **Lossless & Raw Audio:** M4A, WAV, and FLAC support.
- **Custom Save Location:** Select your preferred download folder and click **Set Default** to remember it permanently.
- **Clip Trimming:** Enter start and end timestamps (e.g. `00:15` to `01:30`) to download only the section you want.
- **Embedded Artwork & Metadata:** Automatically embeds artist, title, and thumbnail cover art directly into output files.
- **Lightweight & Clean:** Self-contained native installer (~26 MB) with automatic one-time background setup.
